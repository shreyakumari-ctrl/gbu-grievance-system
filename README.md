# 🎓 GBU Grievance Management System

A modern, responsive **Grievance Management & Ticket Tracking System** built for **Gautam Buddha University (GBU)**. This application allows students to submit grievances, track their status using a unique Ticket ID, and enables administrators to manage and update grievance records through a secure dashboard.

---

## 🚀 Features

### 👨‍🎓 Student Module
- 📝 Submit Grievance Form
- 🎫 Automatic Ticket ID Generation
- ✅ Submission Success Page
- 🔍 Track Grievance by Ticket ID
- 📊 Real-time Status Tracking
- 📅 Submission Date & Time Display
- 📱 Fully Responsive UI

### 👨‍💼 Admin Module
- 🔐 Dummy Admin Login
- 🛡️ Protected Routes
- 📊 Dashboard with Statistics
- 🔍 Search Grievances
- 🎯 Filter by Status
- ↕️ Sort Complaints
- 📄 View Grievance Details
- ✏️ Update Grievance Status
- 💾 Persistent Data using Local Storage

## 💻 Installation

Clone the repository

```bash
git clone https://github.com/shreyakumari-ctrl/gbu-grievance-system.git
```

Navigate into the project

```bash
cd gbu-grievance-system
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
